# 莊馥瑀 Yui｜個人履歷網站

中英雙語的單頁履歷網站。A bilingual one-page résumé site.

- **內容**：定位、工作方式、AI 實作、勤美術館專案、經歷、能力與工具、聯絡方式
- **技術**：原生 HTML、CSS、JavaScript；捲動動態使用 GSAP ScrollTrigger（鎖定版本並驗證完整性）
- **隱私**：沒有後端、沒有追蹤程式、不使用 cookie
- **製作**：由我撰寫 prompt、與 Claude 協作完成

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 整個網站（樣式、文案字典與互動都在同一個檔案） |
| `img/` | 頁面使用的照片，來源見頁面上的圖說 |
| `yui-resume.pdf`、`yui-resume.jpg` | 一頁履歷與其預覽圖 |
